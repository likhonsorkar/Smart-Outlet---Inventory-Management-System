# Smart Outlet 🏪

Smart Outlet is a modern Inventory, POS, and Retail Management System designed to seamlessly connect physical stores with e-commerce operations.

The system is built with a powerful multi-outlet architecture that allows businesses to manage multiple branches from a single platform.

## Outlet Modes

- 🏬 Offline Outlet
- 🌐 Online Outlet
- 🔄 Hybrid Outlet (Online + Offline)

# 🧠 Batch Based Inventory System

Smart Outlet uses a professional batch inventory system where each stock entry can have:

- Different purchase prices
- Different selling prices
- Supplier information
- Expiry tracking
- Outlet-wise quantity management

This allows accurate:

- Profit calculation
- FIFO/LIFO stock handling
- Financial reporting
